# Local literary texts

Full copyrighted literary works and commercial translations are intentionally **not distributed** in this public repository.

To reproduce experiments that require the source texts, obtain lawful copies and place them locally in this directory using the filenames expected by the scripts, for example:

- `1984_original.txt`
- `1984_oldtranslation.txt`
- `1984_newtranslation.txt`
- `hp_original.txt`
- `hp_rosmen.txt`
- `hp_mahaon.txt`

These `.txt` files are excluded by `.gitignore` and should not be committed. Researchers are responsible for ensuring that their local use of the texts complies with applicable copyright and licensing terms.

The repository retains only derived research artifacts needed to document the proof-of-concept analysis, such as cultural-marker tables and aggregate validation summaries.
